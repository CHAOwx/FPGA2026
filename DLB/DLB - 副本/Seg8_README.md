# Seg8 使用说明

`Seg8.v` 集成数值转换、8 位数码管扫描和两片级联 HC595 驱动，适用于参考 ACX720 V3 开发板。

```verilog
Seg8 #(
    .CLK_FREQ_HZ(50000000),
    .SCAN_FREQ_HZ(1000)
) u_seg8 (
    .clk(clk),
    .reset_n(reset_n),
    .data(value),        // 32 位无符号数
    .format(radix),      // 2'b00 二进制；01 十进制；10 十六进制；11 熄屏
    .ds(ds),
    .sh_cp(sh_cp),
    .st_cp(st_cp)
);
```

| 格式 | 显示范围 | 示例（空格表示熄灭） |
|---|---|---|
| 二进制 | 输入低 8 bit | 5 → `     101`；256 → `       0` |
| 十进制 | 输入对 100000000 取余 | 123 → `     123`；100000000 → `       0` |
| 十六进制 | 输入全部 32 bit | 291 → `     123`；4294967295 → `FFFFFFFF` |

数字右对齐，高位零不显示，小数点关闭。七段字形使用参考例程的 `A、b、C、d、E、F`。不显示进制前缀或负号。

`data` 和 `format` 应同步于 `clk`，模块在转换开始时同时采样。转换完成后的结果在下一帧边界提交；中间输入可能被跳过，不提供逐个输入的握手。十进制转换需要 32 个时钟周期，默认情况下稳定输入约在一个 8 ms 刷新帧加转换/发送时间内进入显示帧。

`SCAN_FREQ_HZ` 表示每秒切换的数码管位数，默认 1000，完整 8 位刷新为 125 Hz。每位占用 `CLK_FREQ_HZ / SCAN_FREQ_HZ` 个时钟周期（整数除法），须至少为 160。HC595 移位时钟固定为系统时钟的四分之一，每个 16 bit 数据包发送后才锁存，换位前先锁存熄屏数据。

复位低电平异步生效，释放应同步于系统时钟。复位使三个输出引脚为零；HC595 内部输出寄存器不会被这些引脚直接清空，因此在复位释放后先发送熄屏包，再恢复扫描。

## 仿真与上板

遵循 `DLB/AGENT.md`，工程只填充已有 `Seg8.v`，不新增工程 `.v` 文件。上板测试逻辑统一写入已有 `Test.v`，由用户自行上板。临时自检代码位于工作区 `Claude_Temp/Seg8_validation/Seg8_tb.v`，未加入工程；批处理仿真顶层为 `Seg8_tb`，成功时输出 `PASS`。测试将每位扫描周期缩短至 200 个系统时钟，并通过实际输出引脚模拟 HC595。

当前模块不包含上板输入源，也未添加引脚约束。接入系统顶层后，参考例程对应引脚为：`clk=Y18`、`reset_n=F15`、`ds=M18`、`sh_cp=F4`、`st_cp=C2`，I/O 标准为 `LVCMOS33`；系统时钟约束周期为 20 ns。`data`、`format` 应由顶层内部逻辑提供。

综合时序检查针对默认 50 MHz 内部寄存器路径，不能替代接入最终顶层后的布局布线及板级 I/O 时序验证。
